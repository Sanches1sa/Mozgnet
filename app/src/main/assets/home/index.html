Как получить root (Redmi / Xiaomi, HyperOS)
Без root Android не даёт приложениям менять MAC — поэтому эти кнопки работают только на телефоне с root (Magisk).
0. Сделай копию: разблокировка стирает телефон. Копия облака — панель облака → Система → Экспорт.
1. Обнови HyperOS до последней версии: после разблокировки обновления по воздуху могут перестать приходить.
2. Приложение Xiaomi Community: регион Global, аккаунту больше 30 дней → «Я» → «Unlock bootloader» → заявка.
3. Настройки → О телефоне → 7 раз по «Версия ОС» → «Для разработчиков» → «Статус Mi Unlock» → привязать аккаунт.
4. На компьютере: Mi Unlock, телефон в режиме fastboot (выключить, громкость − и питание) → Unlock.
5. Поставь Magisk, пропатчи им boot.img своей прошивки и прошей: fastboot flash boot magisk_patched.img.
6. Открой mozgnet → «Проверить» → разреши root в окне Magisk. Дальше кнопки делают всё сами.
Если драйвер Wi-Fi возвращает адрес, в настройках этой сети Wi-Fi выбери «Конфиденциальность → MAC-адрес устройства».

Как подключить плату

1. Телефон и плата — в одной сети Wi-Fi (или плата в точке доступа телефона).
2. «Сканировать сеть» → у платы «Подключить к облаку телефона»: плата получит адрес облака и мозг-токен.
3. Облако работает, пока включено «Держать облако включённым». На ночь лучше на зарядке.
4. MAC платы: «повернуть» — один переворот, «вращать…» — плата сама переворачивает MAC через заданные секунды (как в лаунчере). Нужен логин и пароль платы (SSH). MAC самого телефона приложение менять не может — для него в Android есть «Случайный MAC» в настройках Wi-Fi.
Облако на компьютере тоже находится сканом — плату можно подключить к нему.
