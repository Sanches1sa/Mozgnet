Мозг-12 — сторонние компоненты и лицензии

Лаунчер (neuro12-start.exe)
- Go — стандартная библиотека — BSD-3-Clause (вшита в exe): сохранить копирайт и текст лицензии
- golang.org/x/sys (зеркало github.com/golang/sys v0.30.0) — BSD-3-Clause (вшита в exe): то же
- github.com/jchv/go-webview2 — MIT (вшита в exe): копирайт John Chadwick + текст MIT
- github.com/jchv/go-winloader — ISC (вшита в exe): копирайт John Chadwick + текст ISC
- Microsoft Edge WebView2 Runtime — лицензия Microsoft (часть Windows 11, в exe не входит): не распространяем — ничего делать не нужно

Лаунчер для Linux (neuro12-start-linux-amd64 / -arm64, РЕД ОС, Ubuntu)
- Go — стандартная библиотека — BSD-3-Clause (вшита в программу): сохранить копирайт и текст лицензии
- Сторонних библиотек Go в Linux-сборке нет (WebView2 и golang.org/x/sys не входят)
- Окно: Chromium / Яндекс Браузер / Chrome / Firefox — лицензии браузеров (из репозитория ОС, не распространяем)
- OpenSSH, NetworkManager, polkit (pkexec), zenity — BSD / GPL / LGPL (из репозитория ОС, вызываются отдельными программами; не распространяем)

Облако (neuro12-cloud)
- Python 3 — PSF License (ставится установщиком (winget)): не вшит; при поставке вместе — приложить лицензию PSF
- NumPy — BSD-3-Clause (ставится pip): сохранить лицензию при поставке
- Pillow — MIT-CMU (HPND) (ставится pip): сохранить лицензию при поставке
- Vosk (распознавание речи) — Apache-2.0 (необязательно): лицензия + NOTICE
- Модель vosk-model-small-ru-0.22 — Apache-2.0 (скачивается по запросу): лицензия + указать источник alphacephei.com
- pytesseract + Tesseract OCR — Apache-2.0 (необязательно): лицензия + NOTICE
- FFmpeg — LGPL-2.1+ (сборки с GPL-частями — GPL) (отдельная программа, необязательно): при поставке вместе — исходники/ссылка на них
- eSpeak NG (голос) — GPL-3.0 (отдельная программа, необязательно): вызывается отдельно — облако не заражает; при поставке вместе — исходники/ссылка [проверить]
- Модуль yolo_core (YOLO) — зависит от модели (модуль владельца, в поставке нет): если это Ultralytics YOLO — AGPL-3.0 или платная лицензия Ultralytics [проверить]

Плата Arduino UNO Q (neuro_12)
- Arduino App Lab bricks (arduino.app_utils, web_ui) — MPL-2.0 (среда приложения): копилефт по файлам: свои файлы — любая лицензия; изменённые файлы Arduino — открыть
- Arduino_RouterBridge — MPL-2.0 (скетч хаба): то же; мы библиотеку не меняли
- Ядро Arduino для UNO Q (Zephyr) — Apache-2.0 (Zephyr) + LGPL-2.1 (ядро Arduino) (прошивка хаба): LGPL: дать исходники ядра (ссылка) и возможность перелинковать прошивку (объектные файлы скетча) [проверить]
- SoftwareWire (Testato) — GPL-3.0 (в прошивке хаба, ТОЛЬКО если библиотека установлена (LINK_SW_WIRE 1)): тогда вся прошивка хаба — GPL-3.0: открыть исходник скетча покупателям или заменить на аппаратный I2C/свою реализацию [проверить]
- Словари ru_top.json, ru_pos.json — не указана (данные мозга): уточнить, откуда взяты частотные списки (НКРЯ, OpenCorpora и т. п. имеют свои условия) [проверить]

Камера ESP32-CAM (esp32cam_tflite)
- Нейросеть person_detect (int8, MobileNetV1) — Apache-2.0 (вшита в прошивку (n12_model_data.cpp)): © The TensorFlow Authors; модель не изменена; обучена Google на Visual Wake Words (из COCO)
- TensorFlow Lite Micro — Apache-2.0 (в прошивке): лицензия + NOTICE
- TensorFlowLite_ESP32 1.0.0 (+ FlatBuffers, gemmlowp, ruy) — Apache-2.0 (в прошивке): лицензия + NOTICE
- Ядро Arduino-ESP32 (Espressif) — LGPL-2.1 (в прошивке): дать исходники ядра (ссылка) и возможность перелинковать прошивку [проверить]
- ESP-IDF, esp32-camera — Apache-2.0 (в прошивке): лицензия + NOTICE
- FreeRTOS — MIT (в прошивке): копирайт + текст MIT

Что сделать при продаже:
1. Приложить к устройству (инструкция, сайт или меню) тексты лицензий: Apache-2.0, MIT, ISC, BSD-3-Clause, MPL-2.0, LGPL-2.1, PSF — и копирайты авторов из списка.
2. Apache-2.0: сохранить файлы NOTICE проектов и пометить изменённые файлы (нейросеть не меняли).
3. LGPL-2.1 (ядра Arduino на UNO Q и ESP32): указать, где взять исходники ядра, и дать по запросу объектные файлы прошивки, чтобы её можно было перелинковать.
4. MPL-2.0 (Arduino App Lab, RouterBridge): если меняете их файлы — открыть изменённые файлы; ссылка на репозитории Arduino.
5. ⚠ SoftwareWire (GPL-3.0): либо открыть исходник скетча хаба, либо собирать прошивку без неё.
6. ⚠ Уточнить: источник словарей ru_top/ru_pos и, если подключите YOLO, его лицензию.
7. Не использовать товарные знаки (TensorFlow, Arduino, Espressif, Google) так, будто они делают или одобряют устройство.

Справка, не юридическая консультация. Перед продажей проверьте с юристом.
