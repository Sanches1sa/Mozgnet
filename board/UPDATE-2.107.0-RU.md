# neuro_12 2.107.0 — мозг обдумывает формулы
- Раньше формулы только считались по вопросу человека. Теперь мозг сам обдумывает их в мыслях (`_formula_ponder`): берёт формулу по теме вопроса (или каждую 4-ю мысль, `formula_every`), записывает её и проверяет на пробных числах через `_mm_eval`. Настройка `formula_thoughts`.
- Пример: «Обдумываю формулу «Закон Ома»: I = U/R. Проверю на пробных числах: u=8, r=7 — получается 1.1429.»
- Плату это не усложняет: сглаживание разрозненных мыслей делает облако, плата не меняется.
- Проверено тестами (`test_formula_ponder.py`); на живой плате не проверял.
