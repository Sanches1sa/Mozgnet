# Плата 2.111.0 — аппаратный уровень для мозга-12

- Скетч: RPC `hw_io("команда;команда")` — свободные выводы микроконтроллера: D5, D7 и A5 (с 2.111.1; D9 — речь). Команды: `mode P in|out|pullup`, `w P 0|1`, `r P`, `a A5`, `pulse P мс` (до 500 — дольше тормозит цикл мозга), `pins`.
- Python платы: `hw_io()` проверяет команды по белому списку до скетча; задания облака режима `hw` (из App Lab: `ctx.boards.hw`); команда чата `/пин w D7 1`; настройка `hw_on` (по умолчанию включено) — выключает всё это.
- Нужна перезаливка платы (новый скетч). На железе не проверено: пришлите, что ответит `/пин pins` и `/пин a A5`.
