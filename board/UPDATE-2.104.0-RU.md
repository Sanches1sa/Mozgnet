# neuro_12 2.104.0 — речь на D9: драйверы Zephyr возвращены
- `#define NEURO_PCM_MODE 1` (sketch.ino, перед `#include "pwm_voice.h"`): аппаратный PCM (PWM TIM4 + TIM16). `0` — программный PCM без драйверов (digitalWrite, до ~3 с).
- Что исправлено в драйверном варианте (кандидаты на «мост ждёт скетч», которые нашлись разбором кода):
  1. `device_is_ready()` — не inline, а вызов функции ядра (z_device_is_ready), которую llext может не получить -> заменён проверкой указателей (header-only).
  2. Буфер PCM 32 КБ в ОЗУ модуля -> 8 КБ (порог старта = половина).
  3. Буфер RPC pcm_write 512 Б был на стеке потока моста -> static.
- Остаётся неустранимым без железа: `DEVICE_DT_GET` ссылается на объекты устройств ядра; если они не экспортируются llext-ядру, скетч не загрузится — тогда `NEURO_PCM_MODE 0` и лог загрузки (undefined reference ...).
- Проверено только симуляцией (g++); на плате не проверялось.
