# neuro_12 2.108.0 — плата выполняет задания облака

- Плата снова принимает от облака задания `sh` (команда оболочки), `py_check` и `py_run` (Python) и возвращает результат — вместо отказа «питоны убраны».
- Включено по умолчанию настройками `admin_from_cloud` (sh) и `code_from_cloud` (python); выключаются в настройках платы.
- Ограничения: таймаут 2–120 с, вывод до 6000 символов, временная папка, неизвестные режимы отклоняются.
- Самописный код самого мозга по-прежнему не создаётся и не запускается.
- Важно: `sh` выполняется в контейнере приложения. Команд хоста (`arduino-app-cli`, `systemctl`, `reboot`) там обычно нет — для них остаётся SSH.
- Не проверено на реальной плате.
