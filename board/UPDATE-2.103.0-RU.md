# neuro_12 2.103.0 — речь на D9 без драйверов Zephyr
- Программный PCM: только pinMode/digitalWrite/micros (то, что llext грузит; аппаратный PCM ломал загрузку — «мост ждёт скетч»). Звук (8 кГц, 8 бит, до ~3 с) копится в буфере (pcm_begin/pcm_write/pcm_end), по pcm_end loop() проигрывает его блокирующе 1-битной сигма-дельтой на 64 кГц (D9 -> RC-фильтр ~4 кГц -> усилитель).
- Пока звучит, нейроны не опрашиваются (до ~3 с); для коротких слов («Роуз») незаметно. Длиннее 3 с — ответ error:too_long, Python играет через ALSA.
- Нужен RC-фильтр (напр. 1 кОм + 100 нФ) между D9 и усилителем. tts_on=true, tts_output=pwm9.
- ПРОВЕРЕНО только симуляцией (g++); на железе тембр и скорость зависят от скорости digitalWrite: если звук «медленный/низкий» — digitalWrite дольше 15 мкс; напиши, подстрою частоту.
