# 2.99.3 — слияние веток, латиница нейронов, слова вместо молчания, мысли облака

Слияние: плата GitHub 2.99.2 (кадры камеры push, битые кадры, гул 50 Гц, брандмауэр) + архив 2.98.2
(полный снимок 12 нейронов, длинные мысли, русский PCM). Общий предок — 2.96.5; конфликтов 8, все разобраны
(взяты кадры камеры из GitHub, версии и `import neural_bridge` — из новой ветки).

Исправлено:
1. `neural_bridge.to_russian`: privet/zdes/slychu/gotov/tok/volna и названия зон -> русские слова, прочее — общий транслит.
   В пакете остаётся `raw` (исходный транслит). Латинские токены не попадают в `surface()`.
2. Диагностика прохода: `physical_online`/`software_neurons`/`context` есть во всех записях (раньше «undefined»).
3. `reflect(..., fallback_words=True, pool=...)`: после 6 проходов без подтверждения — слова мозга из словаря (phase=`words`).
4. `_neuron_context`: слова программных нейронов служат контекстом, когда аппаратные слов не дали.
5. Письма облака `kind=cloud_thought`: нейроны слушают, окно платы показывает «☁ …», ответа нет.
6. (из 2.98.1/2.98.2) PCM D9 по умолчанию выключен (`-DNEURO_PCM_ENABLE`), слово нейрона очищается от знаков.

Про «пульсируют только две ячейки»: пульс привязан к реальным спайкам пакета (имитации нет). Если стреляют только два
нейрона, остальные платы ответили по I2C, но не набрали порог: проверьте, что на них прошит `sketch/neuron_node`
версии 2.96+ и что на A0 приходит частота с D4 хаба.
