# Исправление запуска 2.97.1

Исправлена ошибка `NameError: name 'api_cloud_search' is not defined` при выполнении `register_web()`. В версии 2.97.0 при изменении TTS был случайно удалён обработчик поиска. Реальная функция восстановлена из 2.96: запрос идёт через настроенное облако, результаты возвращаются панели. Это не заглушка и не отключение маршрута.

Проверка теперь исполняет настоящий register_web с настоящими определениями всех 35 обработчиков и тестовым объектом WebUI. Дополнительно проверены пустой запрос, передача результатов облака и ошибка соединения. Всего 30 тестов приложения. Железо и сборка Arduino/Zephyr здесь не проверены.

## Установка

1. Сохраните память и конфигурацию, остановите приложение в App Lab.
2. Обновите прежнее приложение файлами из neuro12-app-v2_97_1.zip. При создании нового приложения перенесите сохранённые данные: сам ZIP их не содержит.
3. Запустите Run. Python и скетч хаба имеют версию 2.97.1. Облако 3.208 менять не нужно.

Для быстрого исправления без обновления MCU достаточно заменить `python/main.py` в существующем приложении файлом из нового ZIP и перезапустить. Аппаратный протокол не менялся, со скетчем 2.97.0 совместимо; полный импорт обновит номер скетча до 2.97.1.

Память, словари и настройки не удаляйте. Голос на PWM D9 и сборка длинных предложений сохранены; ограничения подключения, eSpeak NG и резервирования TIM16 описаны в UPDATE-2.97-RU.md. PWM остаётся экспериментальным, физическая проверка не выполнена.
