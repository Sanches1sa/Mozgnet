# Приложение neuro_12 2.96 + облако 3.207

## Что изменено

- **Полная сводка 12 аппаратных нейронов.** MCU отправляет отдельный `on_neurons`, а не только TOP и короткий MSG. Каждый слот включает номер, доступность, реальные спайки и слово. Перед сборкой фразы накапливается окно последних 3 секунд. Тихие и недоступные каналы не заменяются выдуманными сигналами.
- **Видимые пульсы.** В интерфейсе плата-нейрон пульсирует при новом пакете со спайками, не по декоративному таймеру. В скетче отдельного нейрона LED теперь держится 60 мс без `delay`; раньше импульс был 600 мкс. Если нейрон не выдаёт спайков, пульс не имитируется. На периферийной плате один переход порога теперь учитывается как один спайк; слово выбирается по сохранённым весам и текущим входам, а не случайным смещением от Гц. Частотный случайный дрейф языковых весов отключён; подкрепление идёт по активному входному стимулу.
- **Локальная сборка с повторной проверкой.** Существующая зонная сеть и тензорная сеть на Linux-части UNO Q выбирают фразу из словарных кандидатов. Контекст берётся из периферийных нейронов и связанных активных нейронов локальной сети. Слова буквогенератора, TOP и частота хаба не подставляются вместо этого контекста.
- **Максимум шесть проходов.** Каждый следующий проход ждёт новый полный снимок нейронов. До шести кандидатов за проход, буфер вариантов ограничен. Нет свежего пакета или подходящей фразы — остановка с причиной, а не публикация случайных слов. В Bridge callbacks нет ожидания, повторных генераций или вызовов Bridge.call.
- **Пунктуация.** Проверяются завершение предложения, повторы, наличие слов в словнике и изученных связей. Запятые/двоеточия берутся из встречавшихся сочетаний в документах и прочитанных статьях, вопросительная форма — из вопросительных слов/зоны. Это ограниченная структурная проверка, не полноценный анализ русской грамматики.
- **Лексика без рангового приоритета.** `lexicon_ru.json` — отсортированный набор тех же слов, без частот и рангов. Слова в обратный канал скетча выбираются из текущего нейронного контекста. Связки «Гц → слово» больше не меняют выбор лексики. Старые таблицы частот сохранены для кодирования/диагностики чувств; пины и аппаратные частотные каналы не удалены. Статистика изученных переходов между словами остаётся частью языковой модели — это не рейтинг слов из частотного списка.
- **Обучение не подменяется повторением.** Успех внутренней структурной проверки не становится положительной меткой. Свои помеченные фразы исключены из корпуса сборки, не учат общий словарь автоматически. Внешние вердикты усиливают/ослабляют существующую зонную сеть и пополняют обучающие примеры тензора. Необученный тензор не становится обученным от шести попыток.
- **Своя LLM облака.** Для свободной генерации `sample` при получении полных свежих нейронных данных действует аналогичный ограниченный цикл до шести свежих контекстов. При отсутствии таких данных сохраняется обычная генерация. Кандидаты проверяются на форму/связь с контекстом, а не объявляются истинными фактами. Прежняя защита технических ответов 3.206 сохранена. Изменения не превращают малую сеть в полноценную большую LLM и не доказывают осознанность.

## Установка

1. Остановите приложение и облако, сохраните резервные копии памяти приложения и всей папки `data` облака. Старые обученные веса и номера нейронов не сбрасывайте.
2. Импортируйте `neuro12-app-v2_96_0.zip` в Arduino App Lab и запустите Run. Должны обновиться и Python, и корневой `sketch/sketch.ino` UNO Q. Версия скетча в диагностике — 2.96.0. Если App Lab создаёт новый каталог приложения, прежняя память автоматически в него не переносится: сначала восстановите сохранённые данные либо обновляйте код в прежнем каталоге, не удаляя файлы памяти. Одного копирования assets недостаточно: без нового MCU-сообщения полный контекст не поступит.
3. Чтобы светодиоды **физических** нейронных плат мигали заметно, прошейте в них `sketch/neuron_node/neuron_node.ino` под фактическую модель каждой платы. Импорт приложения UNO Q сам по себе не прошивает периферийные платы. I2C-протокол, ID и EEPROM сохранены; команды сброса номеров не нужны. Со старым периферийным скетчем новые интерфейсные пульсы и сборка работают, но LED остаётся коротким.
4. Обновите облако до 3.207, распаковав обновление поверх программы. Папку `data` сохраняйте. Перезапустите облако и обновите браузер Ctrl+F5. Веса LLM не переинициализируются; исторические ассоциации внутри уже обученных весов без переобучения не удаляются.
5. В приложении раскройте «Нейроны → локальная сеть → фраза». В диагностике доступны проход, номера пакетов, контекст и причины отклонения. Загружайте связные документы/статьи и используйте обучение существующих сетей и внешние оценки. Одна только пунктуация не подтверждает смысл и факты.

### Ubuntu Server / Linux

Тот же ZIP приложения можно импортировать через Linux-лаунчер облака: выберите серийный номер UNO Q → импорт ZIP → список приложений → нужный ID → запуск. Точный ID берите из списка, а не угадывайте по имени ZIP. GUI на сервере не нужен.

Облако: используйте `neuro12-cloud-linux-v3_207_0-update.zip`, сохраняя `data`. Затем `systemctl --user restart neuro12-launcher` или обычный `bash launcher/linux-start.sh --start-cloud`, в зависимости от вашей установки. Если облако работает отдельной системной службой, перезапустите её.

Для обновления уже существующего каталога приложения по SSH есть `deploy_cli/push_and_run.sh` (LF). Он останавливает прежний `~/ArduinoApps/neuro_12`, архивирует его в `~/neuro12_backups`, переносит файлы без удаления существующей памяти и запускает App CLI. Перед запуском проверьте, что обновляете именно этот каталог: импорт App Lab может создать другой ID/путь. Для новых установок скрипт берёт текущий распакованный проект, без ошибочной вложенной папки neuro_12.

## Проверка и ограничения

Python-тесты проверяют все 12 каналов, свежесть, накопление, шестипроходный предел, отклонение неподходящих вариантов, вход реального bridge callback и внешнее подкрепление. В Chromium проверен интерфейс с тестовой телеметрией. Новые LED-функции проверены C++-тестом времени и переполнения millis; селектор слов проверен на изменение результата при изменении входов и весов.

Полная сборка Zephyr/Arduino и физическое подключение не выполнялись: Arduino toolchain и реальные UNO Q/нейронные платы в среде отсутствуют. После обновления проверьте сборку, версию скетча, передачу полного пакета и проводку на своих устройствах. Архивы содержат исходники, а не заранее прошитые бинарники.
