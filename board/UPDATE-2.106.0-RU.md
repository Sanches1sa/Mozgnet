# neuro_12 2.106.0 — триграммы и переходы между предложениями
- Сеть знаний (`_gen_rebuild`) теперь строит ТРИГРАММЫ «слово1 слово2 → слово3» (до 250 000 ключей, TRI_MAX) из реплик, документов и прочитанных статей. Сборка фразы (`_gen_compose`) со второго слова выбирает продолжение по триграмме (вес ×4), нет триграммы — прежние биграммы; 37 оборотов (`_loop_transfer`) тоже усиливают триграммные продолжения.
- ПЕРЕХОДЫ МЕЖДУ ПРЕДЛОЖЕНИЯМИ (`snext`): основа последнего слова предложения → первое слово следующего (по статьям). `brain_full_text` ставит следующее предложение с того слова, которое в текстах чаще идёт следом (`_pick_next_sentence_seed`); нет статистики — по очереди.
- В журнале при пересборке: «N триграмм, M переходов предложений».
- Эффект на живых мыслях зависит от прочитанных статей: чем больше статей (`read_topics`, вопросы людей), тем плотнее триграммы. Проверено на тестовом тексте; живую плату не проверял.
