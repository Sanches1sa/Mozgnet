# mozgnet — облако «Мозг-12» в телефоне

Android-приложение. Внутри — **то же облако, что на компьютере** (v3.177.0), работает прямо в телефоне.
Есть чат, мозг, своя LLM, база знаний, боты МАКС и Telegram, потоки обучения и обновления через панель.
Ещё приложение сканирует локальную сеть и подключает платы neuro_12.

## Установка на GitHub (автосборка APK)

Windows — двойной щелчок по **`install-github.bat`** (или `install-github.ps1` в PowerShell).
Linux — `bash install-github.sh`.

Скрипт:
1. ставит Git и GitHub CLI, если их нет;
2. открывает браузер, чтобы войти в GitHub;
3. создаёт репозиторий `mozgnet`, закрытый (`-Public` / `--public` — открытый), и отправляет проект;
4. ждёт сборку APK на серверах GitHub (10–20 минут) и скачивает APK в эту папку.

Дальше каждый `git push` в `main` (или запуск скрипта ещё раз) собирает новую версию.
Её можно взять в **Releases** репозитория или вручную в **Actions → mozgnet APK → Run workflow**.

Другое облако в приложение: `install-github.ps1 -Cloud C:\Users\User\AppData\Local\neuro12-cloud`.

Без скриптов: создай на github.com пустой репозиторий и загрузи туда содержимое этой папки,
**вместе с папкой `.github`**. Сборка запустится сама.

## На телефоне

1. Скачай `mozgnet-….apk` из Releases и открой его. Разреши установку из этого источника.
2. При первом запуске облако устанавливается в телефон и запускается (до минуты).
   На экране — адрес для плат, пароль панели и мозг-токен.
3. **«Сканировать сеть»** — ищет платы (порт 7000) и облака на компьютерах (порт 8077) во всей подсети.
4. У платы есть кнопки:
   - **«Подключить к облаку телефона»** — плата получает адрес облака телефона и мозг-токен;
   - **«…к облаку компьютера»** — подключить к найденному облаку компьютера.
5. **«Открыть облако»** — панель облака телефона, вход без пароля. Кнопка **⌂** внизу слева возвращает в mozgnet.

Облако работает, пока в шторке висит уведомление «mozgnet: облако работает». Выключатель — на главном экране.
Новая версия APK ставится поверх старой: память облака (`files/cloud/data`) сохраняется.
Облако, обновлённое через панель («Обновление»), новее облака из APK, поэтому APK его не перезаписывает.

## Устройство

| Часть | Файл |
|---|---|
| окно, стартовый экран, загрузки и выбор файлов | `MainActivity.java`, `assets/home/index.html` |
| облако в телефоне (служба, установка из APK) | `CloudService.java`, `python/mozgnet_runner.py` |
| Python в Android | [Chaquopy](https://chaquo.com/chaquopy/) 17 (MIT), Python 3.12, numpy |
| скан сети, подключение платы | `Scanner.java`, `Bridge.java` |
| автосборка | `.github/workflows/build.yml` |

Безопасность: мост `window.Mozg` (пароль, токен, настройка плат) доступен **только стартовому экрану из APK**.
Страницы плат, облаков и сайты, открытые в окне, его не получают.
Ссылки на интернет-сайты открываются в браузере телефона, а не в окне mozgnet.

APK подписан ключом `app/mozgnet.keystore` (пароль `android`). Это отладочный ключ, нужен, чтобы
новые версии ставились поверх старых. Для публикации в магазинах нужен свой секретный ключ.
