# mozgnet — весь «Star Gate» в одном репозитории

| Папка | Что это | Версия |
|---|---|---|
| `app/` | **mozgnet** — приложение Android: облако внутри телефона, скан сети, подключение плат, вращение MAC плат | 1.1 |
| `cloud/` | **neuro12-cloud** — облако (сервер + веб-панель), то же, что на компьютере и в телефоне | 3.236.0 |
| `board/` | **neuro_12** — приложение платы Arduino UNO Q (App Lab: Python + скетч) | 2.111.3 |
| `launcher/` | **neuro12-start** — лаунчер для Windows и Linux (РЕД ОС, Ubuntu) | 3.167.0 |

Каждый push в `main` собирает всё на GitHub (Actions → «mozgnet») и выкладывает в **Releases**:
- APK телефона;
- zip обновления облака;
- zip платы для App Lab;
- `neuro12-start.exe`;
- пакет лаунчера для Linux.

Облако в APK берётся из `cloud/` при каждой сборке. Достаточно изменить облако в одном месте — оно обновится везде.

## Вращение MAC с телефона

В списке найденных плат есть кнопки **MAC: показать · повернуть · вращать… · стоп · заводской**.
Они делают то же, что лаунчер: по SSH кладут на плату `n12_mac.sh` и запускают его.
- «вращать…» запускает спин на самой плате: она переворачивает MAC через заданное число секунд.
- Нужны логин и пароль платы. Пароль хранится только в приложении. Если у пользователя платы нет sudo без пароля, тот же пароль передаётся sudo через stdin.
- MAC самого телефона приложение менять не может: на это есть «Случайный MAC» в настройках Wi-Fi Android.

## MAC самого телефона (облака) — нужен root

Блок «MAC телефона (облака)» на главном экране mozgnet:
- **Проверить** — показывает загрузчик, root, Magisk и текущий MAC.
- **Повернуть** — перевернуть MAC телефона по тому же правилу, что у платы.
- **Зеркало платы** — телефон получает перевёрнутый MAC платы, как компьютер в лаунчере.
- **Вращать… / Стоп** — переворот каждые N секунд.
- **Вернуть исходный** — первый MAC, который mozgnet увидел у телефона.
- Галочка «вместе с платой» — после поворота MAC платы телефон сам берёт её зеркало.

MAC меняется командой `ip link` через `su`, после смены mozgnet проверяет, что драйвер не вернул старый адрес.
Если у телефона сменился IP, mozgnet отправляет новый адрес облака всем платам из последнего скана.

Без root эти кнопки не работают: Android не даёт приложениям менять MAC.
Пошаговая инструкция «Как получить root» для Redmi и Xiaomi на HyperOS — прямо в этом блоке.

## Установка на GitHub (автосборка APK)

Windows — двойной щелчок по **`install-github.bat`** (или `install-github.ps1` в PowerShell).
Linux — `bash install-github.sh`.

Скрипт:
1. ставит Git и GitHub CLI, если их нет;
2. открывает браузер, чтобы войти в GitHub;
3. создаёт репозиторий `mozgnet`, закрытый (`-Public` / `--public` — открытый), и отправляет проект;
4. ждёт сборку APK на серверах GitHub (10–20 минут) и скачивает APK в эту папку.

Дальше каждый `git push` в `main` (или запуск скрипта ещё раз) собирает новую версию.
Её можно взять в **Releases** репозитория или вручную в **Actions → mozgnet APK → Run workflow**.

Другое облако в приложение: `install-github.ps1 -Cloud C:\Users\User\AppData\Local\neuro12-cloud`.

Без скриптов: создай на github.com пустой репозиторий и загрузи туда содержимое этой папки,
**вместе с папкой `.github`**. Сборка запустится сама.

## На телефоне

1. Скачай `mozgnet-….apk` из Releases и открой его. Разреши установку из этого источника.
2. При первом запуске облако устанавливается в телефон и запускается (до минуты).
   На экране — адрес для плат, пароль панели и мозг-токен.
3. **«Сканировать сеть»** — ищет платы (порт 7000) и облака на компьютерах (порт 8077) во всей подсети.
4. У платы есть кнопки:
   - **«Подключить к облаку телефона»** — плата получает адрес облака телефона и мозг-токен;
   - **«…к облаку компьютера»** — подключить к найденному облаку компьютера.
5. **«Открыть облако»** — панель облака телефона, вход без пароля. Кнопка **⌂** внизу слева возвращает в mozgnet.

Облако работает, пока в шторке висит уведомление «mozgnet: облако работает». Выключатель — на главном экране.
Новая версия APK ставится поверх старой: память облака (`files/cloud/data`) сохраняется.
Облако, обновлённое через панель («Обновление»), новее облака из APK, поэтому APK его не перезаписывает.

## Устройство

| Часть | Файл |
|---|---|
| окно, стартовый экран, загрузки и выбор файлов | `MainActivity.java`, `assets/home/index.html` |
| облако в телефоне (служба, установка из APK) | `CloudService.java`, `python/mozgnet_runner.py` |
| Python в Android | [Chaquopy](https://chaquo.com/chaquopy/) 17 (MIT), Python 3.12, numpy |
| скан сети, подключение платы | `Scanner.java`, `Bridge.java` |
| автосборка | `.github/workflows/build.yml` |

Безопасность: мост `window.Mozg` (пароль, токен, настройка плат) доступен **только стартовому экрану из APK**.
Страницы плат, облаков и сайты, открытые в окне, его не получают.
Ссылки на интернет-сайты открываются в браузере телефона, а не в окне mozgnet.

APK подписан ключом `app/mozgnet.keystore` (пароль `android`). Это отладочный ключ, нужен, чтобы
новые версии ставились поверх старых. Для публикации в магазинах нужен свой секретный ключ.

**3.224 — Контур: имя итогового архива; обновление не ставит чужие файлы (только облако)**
Итоговый архив теперь называется так, как просили в задаче («назови архив мой_релиз», «переименуй архив в «релиз 5»», «сохрани в итог.zip»); если имени нет — имя загруженного проекта с индексом версии: `x.zip → x_v2.zip → x_v3.zip` (в цепочке задач индекс растёт). **3.211 / 2.101 — длинные мысли, 37 оборотов, гибкая LLM, телефон как клиент**
- Мысль платы: перед текстом мозг делает **37 оборотов по словам** (`loop_turns`, `_loop_transfer`): слова вопроса пользователя и нейронов получают приоритет, мысль вписывается в контекст вопроса. Предложений до 10–14 (`thought_sents`), потолок мысли 6000 знаков (был 3800).
- **Облако дополняет мысль**: `POST /api/thought/extend` (wordmind по теме вопроса и слов мысли); отключается `cloud_extend=false` на плате.
- **Сопряжение учит LLM гибкости** (`llm_zones.flexibility`): ширина зонного контекста (до 3 зон), обучение соседних зон и зоны, которую хочет плата, шире выбор слов и температура при застое/расхождении. Настройка `coupling_flex` (0–100, по умолчанию 40); значение видно на странице «Сопряжение».
- **Android-приложение**: карточка «Облако на компьютере / сервере» — телефон подключается к облаку (http или https с закреплением сертификата), своё облако выключается, платы подключаются к облаку компьютера.

**3.210 / 2.100 — HTTPS и мысли облака на D4**
- Облако открывает **HTTPS** (порт 8443, HTTP 8077 остаётся). Сертификат: свой из `data/tls/` или самоподписанный (создаётся сам, SAN = имя и IP компьютера). Отпечаток SHA-256 — `GET /api/tls`.
- `cloud/launcher/install-ssl-linux.sh` — Linux-скрипт: `self-signed`, `letsencrypt` (certbot + хук автопродления), `custom`, `status`, `remove`, `--trust`.
- Плата понимает `https://…` в адресе облака: публичный сертификат проверяет по системным CA, самоподписанный закрепляет при первом подключении (TOFU, файл `neuro12_pin_*.pem`).
- Собственная LLM облака теперь шлёт мысли и на **D4** (`/api/brain/d4`): плата кодирует текст в кадры 32×24 и отправляет через `d4pure`; частоты строк по-прежнему задаёт тензорная сеть платы. Отключить: настройка облака `d4_thoughts=false`.

- **Плата: «Нет полного снимка» / латиница.** Нейрон-платы (классические Arduino) шлют слова только транслитом (`privet`, `gotov`, `volna`…). Раньше Python не переводил их — контекст получался пустым, а программные нейроны учились на латинице («пишет на латыни»). Теперь `neural_bridge.to_russian` переводит слова на входе; латиница в речь мозга не выводится. Слово со знаками препинания больше не отбрасывает весь пакет.
- **Слова вместо молчания.** Если проверка фразы не прошла за 6 проходов, мозг выдаёт русские слова из словаря (помечено «без подтверждения смысла»; настройка `words_fallback`, по умолчанию включена). Без словесного контекста нейронов контекстом служат слова программной сети; в диагностике больше нет «undefined».
- **Облако шлёт свои мысли платам и в чат** (`cloud/server/cloudthought.py`): чат «Мысли плат» + письмо-мысль каждой плате. Настройки/кнопка «подумать сейчас»: `GET/POST /api/cloud/thought`.
- **Лаунчер: облако в домашней сети.** ⚙ → «Облако в домашней сети»: адрес облака на другом компьютере (например `192.168.1.20:8077`) и его токен; плате прописывается оно, своё облако не запускается. В сканере у найденных облаков — кнопка «Облако отсюда».
