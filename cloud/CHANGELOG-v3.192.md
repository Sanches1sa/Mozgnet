# CHANGELOG v3.192.0 — 100 курсов + безопасность и администрирование

## Изменения

- **curriculum.py**: программа обучения расширена до ~104 коротких фактических курсов.
  Добавлены блоки:
  - Информационная безопасность (угрозы, пароли, шифрование, аудит, инциденты и др.)
  - Администрирование серверов (пользователи, службы, SSH, cron, диски, мониторинг и др.)
  - Сети и зоны (IP, порты, DNS, DMZ, зона LLM и др.)

- **codeteach.py**: Яндекс-учитель (и внешний учитель) теперь генерирует уроки не только по Python,
  но и по темам информационной безопасности и администрирования серверов.
  Принятые уроки по-прежнему усваиваются параллельно (в API и ответах) без переписывания основных шагов.

- **llmzone.py**: LLM отмечена как зонная надстройка — дополнение к зонной сети.
  Она сама работает по зонам и не заменяет основные зоны обучения.

## Принцип

Основные шаги обучения не меняются. Новые курсы и уроки от Яндекс-учителя
усваиваются параллельно в существующем контуре (банк уроков → codeboot / learnall / qalearn).
