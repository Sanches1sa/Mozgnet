# neuro12-cloud 3.214.0 — своя LLM сглаживает разрозненные мысли
- Новый модуль `thoughtsmooth.py`. Если мысль платы разрозненна (связность < 0.5), облако собирает из неё нити: предложения группируются по общим основам слов и вопросу, посторонние выбрасываются. Своя LLM (`tinyllm.compose`) добавляет вводную строку «Итог: …» только если она опирается на сами мысли.
- Обновляется ТОЛЬКО копия в банке мыслей облака (`thoughtbank`). Исходная мысль платы не меняется. Код (```), короткие тексты (<3 предложений) и связные мысли не трогаются.
- Настройка `thought_smooth` (по умолчанию включена). Статус: `thoughtbank.stats()['smooth']`.
- Тесты: `cloud/tests/test_smooth214.py`. На живом облаке с реальной платой не проверялось.
