Как подключить мозг к облаку

В настройках neuro_12 на плате укажите адрес Ubuntu, доступный самой плате, и токен из data/token.txt облака. Адрес компьютера, на котором открыт браузер, не подходит автоматически.

Предпочтительно: http://IP_UBUNTU:8077 через общую сеть. Можно создать USB reverse, но доступ к нему из контейнера приложения нужно проверить отдельно.

Установить приложение из ZIP

Выберите исходный ZIP приложения neuro_12 для App Lab (с app.yaml). Облако не содержит исходники платы. Импорт не стирает старое приложение принудительно; при совпадении имени CLI может отказать.
