# 3.239.0 — колебания частиц на отдельных пинах; спин вращается через sudo -n; CI собирает лаунчер

## Колебания частиц на ОТДЕЛЬНЫХ пинах (мюон, гравитон, фотон)
Раньше гравитоны/мюоны/фотоны смешивались на одном пине D6 (`particleTick`). Теперь каждое колебание — свой меандр на своём свободном выводе платы:
- **мюон → D5**, **гравитон → D7**, **фотон → A5**.
- Облако (`oscillations.py`) считает три частоты и отдаёт их платам в ответе опроса `/api/brain/d6` (поле `osc = "m:..,g:..,p:.."`, Гц). Плата выводит меандры в `loop()` скетча (RPC `osc`), частоту обновляет облако.
  - гравитон — медленный (0,3–3 Гц), плавная синусоида;
  - мюон — пакетный (единицы–десятки Гц), случайные скачки и вспышки;
  - фотон — быстрый (десятки–сотни Гц), ярче при активности облака (`osc_gain`).
- Честно: это смоделированные сигналы, а не измерения (на UNO Q нет детекторов частиц). Частоты ограничены 4 кГц — быстрее `loop()` платы не успевает.
- Настройки: `osc_on` (весь блок), `osc_m`/`osc_g`/`osc_p` (по частице), `osc_gain`. API (токен платы): `GET/POST /api/osc`. На плате: чат-команда `/колеб` (показать/«стоп»).
- **Скетч**: добавлен минимальный блок `NEURO_OSC` (RPC `osc` + `oscTick` в `loop()`, три пина, без буферов). Если не хватит памяти llext («мост ждёт скетч») — `#define NEURO_OSC 0`. Версия скетча — 2.114.0.

## Спин «позвонить плате» вращается по-настоящему (sudo -n)
- `mac_spin.set_mac` меняет MAC через **NetworkManager cloned-mac-address** под `sudo -n` (NM не откатывает адрес), запасной путь — `ip link`. Всё под `sudo -n`, без окна паролей на каждом шаге.
- Лаунчер при звонке один раз ставит на плате sudoers (`/etc/sudoers.d/neuro12-mac`: `nmcli`, `ip` без пароля) — дальше звонки идут молча и MAC реально вращается. Нет прав — честный «виртуальный» режим (ритм держится, адрес не меняется, об этом пишется в лог).

## CI собирает лаунчер
- `go.mod` требует Go 1.24, а workflow ставил 1.22 — сборка лаунчера падала. Исправлено: `setup-go` → 1.24 в обоих заданиях (`pc` и `windows`). Теперь каждый push в main собирает Windows `neuro12-start.exe` и Linux-бинарники и кладёт их в Releases.
