# 3.237.0 — самозапись инструкций из интернета, своя LLM на плате, «дружба нейросетей»

## Администрирование: пишет инструкцию сам, когда не знает
- Раньше поиск по памяти почти всегда что-то находил, даже если урок был не про задачу: «настрой zram» превращалось в «SSH: ключи». Теперь мозг считает **покрытие**: какая доля смысловых слов задачи есть в уроке. Если меньше 30%, задача считается незнакомой.
- Незнакомая задача: агент ищет в интернете (Google/Яндекс), берёт команды со страниц из блоков кода и строк `$ команда`.
  - Убирает подсказку `$` и `sudo`.
  - Отбрасывает опасное (`rm -rf /`, `mkfs`, `dd of=/dev/…`, `curl … | sh`, перезагрузка и выключение, `Format-Volume` и др.) и интерактивное (`nano`, `top`, `tail -f`…).
  - Записывает статью «Администрирование: из интернета — <задача> (вN)» и выполняет её.
- **Каждая команда из интернета спрашивает разрешения**, даже при «выполнять без спроса». Опасные спрашиваются всегда.
- В конце задания в чате есть кнопки **«✅ Помогло» / «❌ Не помогло»**. Можно и написать эти слова.
  - **Помогло**: инструкция помечается «Проверено владельцем: да», дальше спрашиваются только опасные команды. Опыт задания остаётся в памяти.
  - **Не помогло**:
    - опыт задания стирается;
    - инструкция помечается «НЕ помогло» и больше не вспоминается;
    - мозг снова ищет в интернете: прежние страницы исключаются, ошибки из вывода добавляются в запрос;
    - записывается версия N+1, и задание запускается снова. Повтор ведёт память мозга, внешняя модель не участвует.
    - Не больше 3 попыток, потом агент просит подсказку.
- Интернет недоступен: берётся ближайший урок памяти, как раньше, с пометкой, что он лишь частично про задачу.
- Выключатель: настройка `admin_selfwrite`.
- API: `POST /api/admin/agent {action: feedback, id, helped}`, `{action: selfwrite}`.

## Своя LLM: скачать и загрузить на плату
- ⚙ → «Своя LLM» → **«⬇ Скачать свою LLM»** (`GET /api/llm/download`). Zip внутри:
  - `model.json`: размеры, словарь BPE, таблица тензоров;
  - `weights.f32`: веса;
  - `board_llm.py`: запуск без облака, с numpy или на чистом Python;
  - `README.txt`.
- Пакет собирается из последней сохранённой на диск точки обучения.
- **«📤 Загрузить LLM на плату»**: пакет ставится в очередь.
  - Плата видит это в опросе `/api/brain/d6` (поле `llm_push`) и скачивает `/api/llm/bundle` со своим токеном.
  - Плата запускает пакет и сообщает итог в `/api/llm/board_state`. Состояние видно в панели.
- На плате команда чата `/ллм текст`.
- Честно: плата только генерирует. Учится LLM в облаке.
- Без numpy на плате генерация идёт на чистом Python: секунды на слово при размере по умолчанию (d=128, 2 слоя).

## Дружба нейросетей — обмен без чата (`netbus.py`)
- Шина пакетов `{from, to, kind, keys, text, conf}` между узлами «мозг», «llm» и «плата:<id>». Фоновый круг обмена идёт раз в 120 с (настраивается).
  1. Мозг берёт тему из свежей статьи знаний и шлёт пакет «знание».
  2. Своя LLM пишет по теме мысль. Мозг проверяет её: качество текста модели плюс совпадение слов с базой знаний.
     - Принял: мысль идёт в нейросеть материалов, доверие мозг→llm растёт.
     - Отверг: доверие падает.
  3. Пакеты уходят на платы через ящик D6 (зона «Дружба сетей») и **проигрываются на пине D6**: текст в PWM-байты, как мысли зон.
  4. Плата отвечает пакетом «отклик»: какие слова узнала её воля мозга. Совпали слова — дружба мозг↔плата крепнет.
- Пакеты от сети с низким доверием не идут в обучение и не уходят на D6.
- Панель ⚙ → «Своя LLM» → «Дружба нейросетей»: включение, «на пин D6», период, «Круг обмена сейчас», доверие и последние пакеты.
- API: `GET/POST /api/netbus`; плата: `POST /api/netbus/post`.
