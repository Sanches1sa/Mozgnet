# 3.219.0 — библиотека инструкций для агента администрирования

- 157 инструкций: плата UNO Q (25), облако (14), Linux (80), Windows (38). Файлы `server/instructions/*.json`, генератор `tools/build_instructions.py`.
- Формат: id, title, ask[], target, risk (read/change/danger), slots, steps (run/check/cloud/wait/note/restart_cloud/…), verify, rollback, notes, verified.
- Агент берёт инструкцию из памяти мозга (БЗ) и идёт по шагам; параметры подставляются из задачи, лишнее отсекается; `expect` и `stop_on_fail` останавливают при сбое; change/danger — только с разрешением владельца.
- Новые инструменты агента: `cloud` (операции самого облака, работают и на Windows), `wait`, `note`.
- Инструкции платы/облака подбираются, только если задача их называет.
- Свои инструкции: `data/instructions/*.json`, `GET/POST /api/instructions`.
- Справочник API платформы (279 маршрутов) — знание в БЗ.
- Корпус для обучения своей LLM (поток «admin»): урок + примеры под разные формулировки.
- Честно: ни одна инструкция не проверена на реальном железе (verified=false); планирование — поиск по памяти, а не свободное рассуждение.
- Тесты: `tests/test_instructions219.py`.
