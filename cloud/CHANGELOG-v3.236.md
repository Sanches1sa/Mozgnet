# 3.236.0 — вместо «шаг 0 из 0 (0%)» видно, чем занято обучение

После «Применить размеры и переобучить» обучение сначала собирает корпус из базы знаний, строит словарь, переводит тексты в токены и готовит план — на большой базе это минуты, а число шагов известно только после первого шага. Всё это время панель показывала «шаг 0 из 0 (0%)», будто ничего не идёт.

- Панель показывает этап: «подготовка: собираю корпус из базы знаний / строю словарь по N текстам / перевожу тексты в токены / готовлю план обучения / первый шаг обучения … (N с)». Когда шаги посчитаны — обычное «шаг X из Y».
- Если текста для обучения слишком мало, обучение раньше молча останавливалось (снова «0 из 0»). Теперь в панели: «⚠ в базе знаний мало текста для обучения… добавьте статьи или уменьшите контекст».
- Тесты: `tests/test_llm_apply235.py` (+2).
