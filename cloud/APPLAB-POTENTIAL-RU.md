# Потенциал записи App Lab мозгом-12

## Что можно делать уже сейчас (3.226)
1. **Писать приложения и кирпичики по просьбе** (чат «Код и App Lab», команда платы `/апп`): «напиши приложение …», «напиши кирпичик …». Основа — 27 инструкций App Lab и 106 уроков кода; перед записью мозг читает страницы в интернете и сверяет свой код с их примерами.
2. **Проверять**: на заглушке при записи, вживую — «проверь <имя>». С платы: `/апп проверь <имя>`.
3. **Вызывать**: по триггерам, по имени («запусти функцию …»), по контексту (смысл фразы + тема диалога). Только включённые владельцем.
4. **Запоминать**: каждое приложение хранит контекст, источники (адреса), автора; события идут в журнал, по нему учится своя LLM.
5. **Администрировать** в отдельном чате с историей: задания агента, инструкции из БЗ.

## Что можно развить (не сделано)
- Подключить обученную свою LLM как автора для задач без шаблона (сейчас — только шаблоны).
- Смысловой подбор контекста (эмбеддинги/зонная сеть вместо совпадения корней слов).
- Автоматически проверять приложения «вживую» по расписанию и отключать упавшие.
- Брать из интернета не только примеры, но и API-справку и сверять сигнатуры.
- Кирпичики облака (`applab.BRICKS`) из приложений — после ручного ревью разработчиком.
- Запуск приложений на самой плате (сейчас плата только просит облако).

## Границы
Не проверено на железе и живых страницах. Код со страниц — недоверенные данные: в приложения не вставляется. Включает приложение только владелец.
