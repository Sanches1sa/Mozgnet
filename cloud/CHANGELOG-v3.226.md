# 3.226.0 — Star Gate пишет App Lab по интернету; вызов по контексту; чаты «Администрирование» и «Код»; App Lab с платы

- `applab_brain.py`: «напиши приложение/кирпичик …» → интернет (поиск, до 2 страниц, блоки кода как НЕДОВЕРЕННЫЕ данные) → основа из проверенных шаблонов (инструкции App Lab, уроки кода) → **сверка**: общие вызовы, чего нет у меня, опасное на страницах (subprocess, os.system, eval, requests… — не берётся) → проверка на заглушке ctx → сохранение **выключенным** с `context`, `web_refs` (адреса), `written_by`. Нет шаблона — честный отказ («свободно новое пишет только обученная LLM»), страницы показываются как примеры.
- «проверь <имя> [на фразе …]» — живой запуск (в т.ч. выключенного приложения); «запусти <имя>» — только включённое; «приложения» — список.
- **Вызов по контексту** (`pyapps.match_context`, хук в `brain`): фраза и тема последних реплик по смыслу совпали с контекстом включённого приложения (≥2 общих корня и ≥½ корней фразы) — вызывается без триггеров. Выключенные не вызываются.
- **LLM наблюдает:** каждое написание/проверка/запуск/контекстный вызов — в `applab_observed.json` → поток обучения своей LLM (`admincorpus.applab_texts`, код с `# task: App Lab: …`).
- **Постоянные чаты** `chat-admin` («🛠 Администрирование») и `chat-code` («⌨ Код и App Lab»): общие, всегда в списке, не удаляются, вся переписка в истории. Админ: «выполни: …» → задание агента администрирования (опасное ждёт подтверждения), «статус <id>», вопросы — по инструкциям из БЗ. Код: App Lab → кодинг-агент → мозг. `POST/GET /api/chat/special`.
- **С платы:** `POST /api/brain/think` с `mode=applab` (команда платы `/апп …`, плата 2.110.0). Приложения от платы — выключенные.
- Честно: не проверено на железе, живом интернете и реальных страницах (в тестах страницы подменены); «понимание контекста» — совпадение корней слов, не смысловая модель; опасный код со страниц в приложения не попадает, но код приложений читает владелец до включения.
- Тесты: `tests/test_applab226.py` (10); весь набор cloud и board проходит.
