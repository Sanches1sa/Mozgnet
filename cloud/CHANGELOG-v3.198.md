# v3.198.0 — собственное обучение чтению текста с фотографий

Это изменение добавляет обучение весов по пикселям, а не передачу результата Tesseract в LLM. Добавлена собственная OCR-голова зоны «Камера»: нормализованные изображения символов 20×24 → нейросеть MLP с 96 скрытыми нейронами → символы. Учебные пары задаёт пользователь: фотография печатной строки и её правильный текст. Градиентное обучение меняет веса OCR-головы. Существующие веса текстовой LLM не сбрасываются и не переименовываются в зрительные. LLM использует результат своей OCR-головы через общий адаптер зоны «Камера».

## Как обучать

1. Сделайте резервную копию data и установите обновление. Перезапустите облако и МАКС. Обновите страницу без кэша.
2. В Python-окружении облака нужны NumPy и Pillow: `python -m pip install numpy pillow`. Tesseract для обучения собственной OCR-головы не нужен; внешние сервисы не используются.
3. Откройте настройки → «Обучение чтению фото». Выберите фотографию, обрезанную до горизонтальной строки печатного текста без рамок и посторонних объектов. Введите точный текст и нажмите «Добавить пример».
4. Добавьте минимум три различных фотографии. Первая и далее каждая пятая фотография остаются проверочными: модель не обучается на их символах. Для реального результата нужны десятки разных примеров каждого символа, разные шрифты, масштабы и освещение. Все нужные символы должны встречаться в учебной части; неизвестные символы проверочной части отмечаются в метриках.
5. Нажмите «Обучить / продолжить». Обучение идёт в фоне; «Обновить состояние» показывает эпоху, ошибки, точность на учебной и проверочной частях. Маленький набор не доказывает способность читать произвольные фотографии.
6. Выберите новую фотографию и нажмите «Распознать своей моделью». Подпись при этой проверке не используется. Неуверенные символы заменяются знаком �; численная уверенность не является гарантией точности.
7. После обучения обычные фотографии в чате, кадры камер и фото из МАКС используют собственную OCR-голову. В описании указан движок `own_pixel_mlp`. Без собственных весов сохраняется прежний явно обозначенный путь Tesseract, если он установлен.

Обучение продолжается с сохранённых весов. При расширении алфавита сохраняются прежние скрытые веса и столбцы уже известных символов. Повторное добавление того же файла исправляет его подпись, не переводя фотографию между учебной и проверочной частями. Результаты автоматического распознавания не становятся правильными учебными подписями сами по себе.

## Честные ограничения

Это начальный обучаемый распознаватель печатных строк с раздельными символами, а не готовая универсальная система OCR. Сплошной текст, рукопись, наклон, сложный фон, слипшиеся буквы, отдельные точки, диакритика и многострочные фото могут не сегментироваться. При несовпадении числа выделенных символов и подписи пример отклоняется — модель не учится на ложном выравнивании. Полноценное чтение таких фото потребует более сложной зрительной архитектуры и большого размеченного корпуса.

Словарный профиль зоны и OCR-веса — разные данные. OCR-веса действительно обучаются; текстовая LLM не получила новый вход пикселей в свой трансформер. Никаких обещаний мгновенного обучения или заранее запрограммированных расшифровок нет. Код платы neuro_12 не меняется.

Данные: `data/photo_ocr_samples.json` (подписи, выделенные пиксельные признаки, постоянное разделение набора), `data/photo_ocr.npz` (веса), `data/photo_ocr_metrics.json` (последняя проверка). Они не включены в обновление и сохраняются при обычной установке поверх. API панели: GET/POST `/api/llm/photo-ocr`, действия `add`, `train`, `read`.

Проверено: реальное обучение на простых синтетических изображениях букв, точность на отложенных изображениях, чтение нового изображения, сохранение/загрузка и продолжение обучения, отказ при несовпадении подписи, сохранение проверочной группы при исправлении подписи, отказ от ложного распознавания без весов. Chromium: вкладка, API состояния, ошибка при недостатке примеров, отсутствие ошибок JavaScript. Эти проверки не являются оценкой качества на реальных фотографиях документов.
