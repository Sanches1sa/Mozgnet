# 3.230.0 — Star Gate собирает приложения из кирпичиков, учится на ваших приложениях и правках; уроки ИБ

**1. Кирпичики и планировщик** (`server/brickplan.py`). 19 проверенных кирпичиков `b_<имя>(x, ctx)` с этапом, типами входа/выхода, словами задачи и тестом: строки, неудачные входы (sshd/PAM/Windows 4625), IP, ссылки, IOC (MD5/SHA1/SHA256, IP, домены, почта), почта, числа, CSV, хронология, только внешние IP, подозрительные ссылки (признаки фишинга), подсчёт, порог («больше N»), статистика, сверка со списком блокировок (в т.ч. «запомни блок: …»), надёжность пароля (не сохраняется), отчёт, чек-лист реагирования на инцидент, сохранение в базу знаний.
Планировщик выбирает по словам задачи лучший кирпичик на этап, сам вставляет переходники (текст→строки, записи→подсчёт, любое→отчёт), собирает `main.py`, проверяет запуском. Нет данных во фразе — приложение показывает работу на образце. Пример: «Можешь написать приложение в апп лаб для проверки инцидента по ИБ?» → строки → неудачные входы → отчёт → чек-лист. В чате «Код»: «какие кирпичики», «план: <задача>»; `GET /api/bricks[?q=|?verify=1]`.

**2. Обучение на ваших приложениях.** Включили приложение — оно становится выученным шаблоном (похожая задача соберётся из него). Функции `b_*` с docstring «Кирпичик: название | этап: N | вход: T | выход: T | слова: …» во включённых приложениях сами попадают в библиотеку кирпичиков. Ваша правка кода приложения мозга — урок «было → стало» (база знаний + поток обучения LLM). Кирпичик, написанный мозгом по уроку, сразу оформляется в этом формате.

**3. Уроки.** +9 инструкций App Lab (всего 37): как мозг собирает из кирпичиков, как написать свой кирпичик, ИБ — неудачные входы, фишинг-ссылки, IOC, пароль, внешние IP, хронология, статистика. Все примеры запущены. База знаний пересеется (`ssh_seed_ver` 8).

**Контур** понимает и вопросительную форму: «Можешь написать / нужно приложение … в апп лаб …?» — и вырезает из неё задачу.

Честно: сборка — по словам задачи из известных блоков, а не понимание смысла; на реальных журналах вашего сервера не проверялось. Тесты: `tests/test_bricks230.py` (9), весь набор проходит.
