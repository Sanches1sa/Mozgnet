# 3.234.0 — инструмент кирпичиков, автошаблоны-цепочки, аппаратный уровень для мозга-12 (плата 2.111.0)

- **Инструмент кирпичиков** (App Lab → «🧱 Кирпичики мозга-12 и шаблоны-цепочки», `POST /api/bricks`): свой кирпичик `b_<id>(x, ctx)` — название, этап 1–7, вход/выход, слова задачи, код, тест (assert), образец данных. Проверка: синтаксис, запрещённое (subprocess, eval, exec, open, socket…), тест в песочнице App Lab. Сохранённый кирпичик сразу участвует в цепочках; удаление — там же. Кирпичик, который пишет сам мозг («напиши кирпичик …»), тоже попадает в библиотеку (`bricks_user.json`).
- **Автогенерация шаблонов** (`brickplan.autogen`): мозг перебирает цепочки по этапам и типам, собирает каждую, запускает на образце данных и оставляет рабочие (`brick_templates.json`); не смешивает ИБ, данные и железо и ставит кирпичики только после подходящих (ссылки → «подозрительные ссылки», показания → «правило»). Пересборка — кнопкой, в чате «сгенерируй шаблоны» и сама после сохранения кирпичика. «→ в App Lab» — приложение из шаблона (выключенным). Мозг использует автошаблон, если планировщик не собрал цепочку. Шаблоны идут в обучение своей LLM.
- **Аппаратный уровень:** `ctx.boards.hw("w D7 1; a A5")` в приложениях — команды микроконтроллеру платы через задание режима `hw` (`boardcode`). Свободные выводы: D5, D7, D9 (выход, ШИМ на D5/D9) и A5 (АЦП); выводы мозга не трогаются. Кирпичики: «Прочитать выводы платы», «Включить/выключить вывод платы», «Правило: порог → вывод». Пример: «если показания датчика больше 600 включи D7» → прочитать A5 → правило → D7.
- Уроки App Lab: +4 (инструмент кирпичиков, аппаратный уровень, правило порога, включение вывода) — всего 41.
- Тесты: `tests/test_bricks234.py` (8). Проверено в браузере: проверка и сохранение кирпичика, генерация шаблонов.
- Честно: аппаратный уровень на железе не проверялся — нужна плата 2.111.0 (новый скетч с `hw_io`). Мозг собирает код из блоков и уроков, а не пишет произвольный C++ для микроконтроллера: прошивку скетча он не меняет.

## 3.234.1
- Аппаратный уровень сужен до действительно свободных выводов: **D5, D7, A5**. D9 занят речью PCM, а ШИМ на D5 делил бы таймер с выходом слов D6, поэтому ШИМ из кирпичиков убран («шим …» отвечает, почему недоступно). Нужна плата 2.111.1 (исправлено «мост ждёт скетч» после 2.111.0 — см. `board/UPDATE-2.111.1-RU.md`).
