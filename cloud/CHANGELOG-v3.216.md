# neuro12-cloud 3.216.0 — агент «Администрирование»: честно, с кодом в облаке и со справочником команд
Плата откатана до 2.107.0 (команды чата 2.108 убраны). Меняется только облако.

## Что было не так
1. Плата 2.97.3+ на любое задание из облака отвечает «питоны убраны», при этом сама сообщает `code/admin = true`. Агент видел «✗ команда» без объяснения.
2. «Код» для платы писался и отправлялся на плату — туда, где исполнение отключено.
3. Агент знал ~20 уроков и десяток намерений; всё остальное падало в «обзор сервера». Латинские команды дополнительно отсекал фильтр `strict.text_ok` (>20% латиницы в ответе без слов «код/скрипт…» = «мусор») — знания по командам «блокировались».

## Что сделано
- **Честность:** отказ платы распознаётся (`boardcode.is_refusal`), плата помечается `blocked` (в списке целей `code/admin = false`), агент пишет понятную причину и не повторяет команду. Если Linux платы добавлен в «Серверы» по SSH (по IP/имени), команда автоматически идёт туда, в ответе пометка «выполнено по SSH».
- **Код — в облаке:** новая цель «облако (этот компьютер)» (`local:cloud`, включается «Терминал и рабочий стол» в Настройках → Общие). Мозг пишет скрипт (`code`), кладёт в `~/neuro12-agent/`, проверяет синтаксис и запускает здесь. Если плата блокирована, а просят «напиши скрипт на плате», код пишется и запускается в облаке. Правила подтверждения прежние: изменения — кнопка «Разрешить», опасное — всегда.
- **Знания:** `admincmds.py` — справочник из 56 намерений (процессы, память, диск, S.M.A.R.T., температура, сеть, DNS, порты, файрвол, Wi-Fi, systemd, journal, входы по SSH, Docker, nginx, cron, git, pip, USB/камеры, звук, GPIO/UART, Arduino App Lab, Windows по SSH…). Им пользуются правила агента (вместо слепого обзора), подсказка модели-планировщика (шпаргалка) и обучение: 56 уроков с командами в ```bash идут в базу знаний (досев `ssh_seed_ver=2`) и в поток «admin» своей LLM.
- **Фильтр:** `strict.code_question` теперь считает вопросами про команды слова «команда, терминал, bash, sudo, ssh, linux, сервер, docker, systemctl, служба, cron, git…» — латиница в ответах про администрирование больше не отсекается.
- Тесты: `cloud/tests/test_admin216.py`. Без живой платы и SSH-сервера не проверялось.
