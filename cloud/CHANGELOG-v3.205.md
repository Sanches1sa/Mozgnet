# v3.205.0 — Linux-лаунчер для Ubuntu Server и UNO Q

Новый веб-лаунчер `launcher/neuro12-linux.py`: работает без GUI сервера, панель открывается локально или через SSH-туннель. Нужен Python 3; внешних Python-пакетов самому лаунчеру не требуется. Для USB нужен adb, для основной LLM — NumPy.

- Запуск, проверка /api/health, журнал и остановка собственного процесса облака. Существующее внешнее облако повторно не запускается и не останавливается.
- Обнаружение USB/ADB, выбор серийного номера, диагностика UNO Q, список приложений.
- Импорт собственного ZIP App Lab через ADB и установленный на UNO Q Arduino App CLI; отдельный запуск/остановка и автозапуск выбранного приложения.
- USB forward для веб-интерфейса платы, отдельная команда reverse для облака. Контейнерная доступность облака требует проверки; сетевой IP Ubuntu остаётся рекомендуемым вариантом.
- Пользовательская systemd-служба и инструкция автозапуска без рабочего стола.
- Loopback-only HTTP, случайный токен лаунчера, проверка Host/Origin, проверка ZIP и фиксированный набор действий без произвольного shell-ввода.

Исходники приложения neuro_12 и прошивка в облако не добавлялись и не менялись. Прежние бинарные лаунчеры сохранены. Изменения сопряжения 3.204 включены; веса и пользовательские данные не входят в обновление.

Проверены 11 тестов (включая HTTP-права доступа и управление реальным тестовым процессом), синтаксис shell/Python и путь через Chromium с заглушкой ADB. Физическое USB-подключение, прошивка и запуск на пользовательской UNO Q не проверены. Инструкция: docs/LINUX-LAUNCHER-RU.md.
