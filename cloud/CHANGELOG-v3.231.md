# 3.231.0 — агенты «Код» и «Администрирование» работают из чата, всё в истории

- **Панели агентов над чатом убраны.** В режимах «Код» и «Администрирование» сообщения идут в чат (`/api/chat/send`) и сохраняются в истории вместе с ходом и итогом агентов. Настройки — только «⚙ Настройки агента» внизу чата (интернет, модель, усилие, воля, изменения без вопросов, цель и режим админа, кнопка «Обучить свою LLM коду»).
- **ZIP/RAR в чат (📎) = новый проект этого чата** (`chat_agents.bind_project`, `POST /api/code/project/upload?chat=`): чат переключается в «Код», приходит сообщение о проекте. Каждое сообщение — задача «Контуру» с настройками агента; следующая задача продолжает результат предыдущей. Ход (план, интернет, предупреждения) и итог со ссылкой «📥 Скачать проект, изменения и отчёт» приходят в чат. «убери проект» — отвязать; «?вопрос» — спросить, не трогая проект; «проверь/удали/включи приложение», «какие кирпичики» — App Lab.
- «Напиши / можешь написать приложение … в апп лаб …» в чате с проектом — сразу в App Lab при **любой** модели (раньше с моделью «auto» без LLM Контур отвечал «своя LLM не дала кода»).
- **Администрирование из чата:** сообщение — задача агенту (режим, цель, авто-разрешение — из настроек); шаги приходят в чат, запрос разрешения — сообщением, ответ «да»/«нет» в чате, «стоп» — остановить, «статус». Вопросы («как…», «что такое…») — ответ по инструкциям/мозгу, агент не запускается.
- Открыли чат, где агент ещё работает, — страница сама ждёт его сообщений.
- **Исправлена регрессия 3.230:** новые уроки ИБ в базе знаний (журналы, ssh) сдвинули поиск памяти администрирования — агент «проверь сервер» не доходил до журнала упавшей службы и мог предложить «перезагрузку». Теперь память ищет шире и по симптомам берёт только читающие инструкции (`brainplan`).
- Тесты: `tests/test_chat_agents231.py` (4: настоящий Контур из чата, App Lab из чата, админ с разрешением «да», вопрос без агента); весь набор проходит. Веб проверен в браузере: ZIP → проект → вопрос «Можешь написать приложение в апп лаб для проверки инцидента…?» → приложение в App Lab.
