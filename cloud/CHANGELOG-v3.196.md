# v3.196.0 — зоны LLM, сопряжение, общение и сеть МАКС

- Добавлены зонные контексты своей LLM и обучаемые словарные профили. Используются существующие общие веса: это не набор отдельных нейросетей и не обещание мгновенно обучить модель программированию. Обычные учебные тексты получают зонный контекст; формат обучения коду сохранён. Уже обученные веса не сбрасываются.
- Сопряжение объединяет все известные зоны: базовые зоны, полученные от платы и накопленные при обучении. Доля сигнала LLM регулируется. Объединённая активность используется при генерации и распределении потоков. Отсутствующий сигнал отображается честно; устаревшая активность не выдаётся за текущую. Прошивка neuro_12 не меняется.
- Добавлена вкладка «Общение»: краткость ответа, использование сети при нехватке знаний, ссылки на источники и связанные настройки ответов. Убрана устаревшая информационная настройка режима; поля не дублируются при переходах вкладок. Разделы настроек собраны в раскрывающиеся боксы. Управление квантами, D6 и D4 сохранено.
- В выборе поисковиков теперь явно доступен «Яндекс Search API v2 (ключ + Folder ID)». Это отдельный вариант от анонимной Яндекс-выдачи, которая может требовать капчу. Сохранённые ключи и Folder ID используются без повторного ввода.
- Облачный чат и МАКС используют общий путь ответа. Если знаний не хватает или явно запрошена свежая информация, разрешён поиск. Пустой ответ и «не знаю» из памяти не блокируют его. Подтверждённый источниками ответ не отбрасывается из-за сторонней проверки TCP. Сетевая попытка и источники доступны в объяснении ответа. Ответ без источников не подменяется выдуманным результатом поиска.

## Установка

1. Сохраните резервную копию каталога приложения, особенно data.
2. Установите ZIP через штатное обновление облака либо остановите облако и распакуйте поверх существующего каталога neuro12-cloud. Каталог data сохраняется; архив пользовательских данных не содержит.
3. Перезапустите облако и отдельный процесс МАКС, если он запускается отдельно. Обновите страницу с очисткой кэша (Ctrl+F5).
4. В «Общие → Интернет» выберите «Яндекс Search API v2», сохраните настройки. В «Общение» разрешите поиск. Проверьте поиск в МАКС явным запросом «Найди в интернете …».
5. В «Сопряжение» включите зонные контексты, настройте долю LLM. Для накопления новых зонных профилей продолжайте обычное обучение; новый переключатель сам по себе не меняет знания весов.

## Проверка и ограничения

Пройдены модульные проверки зон, сетевого пути, Яндекс API, сопряжения, потоков LLM и МАКС; синтаксис Python/JavaScript. В Chromium проверены сохранение, отсутствие повторных ID при переходах, выбор Яндекса, все зоны, группы и сохранность квантов/D6/D4. Реальная плата и отправка сообщений в действующий МАКС не проверялись. Рабочих пользовательских ключей в среде сборки нет; авторизованный запрос к Яндексу не выполнялся. Без обучения качество собственной LLM автоматически не повышается.
