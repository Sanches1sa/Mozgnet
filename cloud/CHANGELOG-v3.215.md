# neuro12-cloud 3.215.0 — журнал мыслей, сборка только разрозненных, длиннее мысли LLM
- Плата не менялась (2.107.0): обновляется только облако.
- `thoughtjournal.py` + `GET/POST /api/thoughts/journal` (POST {"clear":true} очищает) + панель «Журнал мыслей» на вкладке LLM. Записи: мозг — связная мысль оставлена; LLM — собрала (связность до/после, нитей, убрано, итог) / не вышло (причина: модель не обучена, итог про другое…) / своя мысль (источник, длина, качество) / отказ.
- Сборка (`thoughtsmooth`): связную мысль (≥ порога, `thought_smooth_thr`, 0.5) LLM не трогает — отвечает мозг. Разрозненную собирает: нити, до 3 итоговых предложений (по каждой крупной нити). Результат — копия в банке и мысль LLM в журнале мыслей. Мысль платы не меняется.
- Мысли LLM длиннее: `_grow` достраивает их предложениями до `llm_thought_chars` (200…3000, по умолч. 900); `extend` — до 3 фрагментов по фактам.
- Банк не разбирает одну мысль дважды (`oid`).
- Тесты: test_journal215.py. На живой плате и обученной LLM не проверялось: если модель «не обучена», в журнале так и будет написано.

## 3.215.1 — сборка работает и без обученной нейромодели
- Раньше при необученной LLM журнал писал «собрать не вышло: модель не обучена» и мысль оставалась разрозненной. Теперь без нейромодели мысль собирается ПРАВИЛАМИ: нити по общим словам, внутри нити главное (самое «центральное» и по теме вопроса) предложение идёт первым, дальше цепочка по общим словам, лишнее убирается. Итоговые предложения от нейромодели добавляются, только когда она обучена.
- В журнале видно режим: «собрано правилами, нейромодель не использована (причина)».
