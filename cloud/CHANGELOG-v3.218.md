# neuro12-cloud 3.218.0 — агента планирует мозг (память), а не ключевые слова
Только облако.
- **Планирование без ключевых слов в коде.** Раньше, если внешняя модель не настроена, шаги выбирали регулярки (`_rule_plan`). Теперь их выбирает мозг облака по своей памяти (`brainplan.py`): поиск по базе знаний (тот же, которым мозг отвечает в чате) по задаче владельца и по строкам вывода прошлого шага (ошибки, предупреждения, проценты) → уроки «Администрирование: …» → шаги из лучшего урока по очереди, выполненные пропускаются. Свободно планирует внешняя модель (если настроена), как и раньше.
- **Как идёт агент:** берёт лучший урок по задаче и доводит его до конца; затем смотрит на вывод шагов, называет замеченное словами («диск заполнен», «упавшая служба», «высокая нагрузка»…) и ищет в памяти урок под это — так «проверь сервер» с полным диском продолжается шагами по диску. Здоровый сервер: остановка без «лишних» команд (макс. 8 шагов из памяти).
- **Что в памяти:** команды Linux (56 тем), команды Windows/PowerShell (46), инструменты агента (перезапуск облака, снимок экрана, камеры, окна, список целей, проверка, включение по сети, «напиши скрипт»), старые уроки. Посев по стабильным id (без дублей), версия посева 3 — при запуске облака добавится сам.
- **Мозг учится:** успешное задание записывается в базу знаний («Администрирование: опыт — …», шаги и результат) и дальше находится поиском.
- **Перезапуск облака** — инструмент `restart_cloud` (подтверждение владельца, если не включено «без вопросов»): сохраняет память, процесс поднимается на том же порту; агент завершает задание сразу.
- **Честно:** если в памяти ничего подходящего, агент не подставляет «общий обзор», а пишет «не нашёл в своей памяти, как это сделать» и как уточнить (команда в `обратных кавычках`, внешняя модель). Каждый шаг помечен, откуда он взят («память: «Процессы» (оценка)»).
- **Граница:** это поиск по выученному, не свободное рассуждение; мелкая своя LLM не умеет надёжно писать команды (она пишет заметку и Python-код). Шаги с параметрами рабочего стола (клик, ввод) планирует только внешняя модель.
- Окно «Серверы» (ssh_agent) пока со старыми правилами. Тесты: test_admin216.py (15). Не проверялось на живом облаке.
