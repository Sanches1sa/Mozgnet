# 3.232.0 — App Lab: включение не «молчит» на Windows, кнопка «Переименовать»

- **Не включалось приложение.** Запись `app.json` делалась прямым `os.replace` без повторов. На Windows замена падает `PermissionError`, пока файл открыт (его читает другой поток облака или антивирус проверяет только что созданный файл) — запрос падал, а страница перерисовывала список как ни в чём не бывало, и галочка «включено» не держалась. Теперь запись повторяется (до 25 раз, как в `store.save_json`), с отдельным временным файлом на поток; код приложения пишется так же. Не вышло всё равно — App Lab показывает ошибку и возвращает галочку.
- **✎ Переименовать** у каждого приложения в App Lab (`POST /api/applab/rename`). Меняется имя; id, папка, код и триггеры остаются. В чате: «переименуй приложение <id или имя> в <новое имя>».
- Тесты: `tests/test_applab232.py` (4: включение при «занятом» файле, честная ошибка, переименование через API и чат). Проверено в браузере: включение и переименование.
- Честно: причину на вашем Windows я не видел вживую — это самая вероятная (свежий файл, сразу занятый), под неё и исправлено; если не включится и теперь, App Lab покажет текст ошибки — пришлите его.
