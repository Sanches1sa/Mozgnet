# neuro12-cloud 3.217.0 — агент администрирования: Windows и подбор команд по смыслу
По скриншоту: агент всегда выполнял три одинаковые команды, а вывод был в «ромбиках».
- **Причина «ромбиков»:** облако работает на Windows, а агент слал Linux-команды (uptime, free, systemctl), которых там нет; ошибки консоли шли в кодовой странице cp866. Теперь локальная цель на Windows выполняет команды в PowerShell с выводом в UTF-8, а при другой кодировке вывод декодируется (utf-8 → cp866 → cp1251).
- **Windows-справочник:** для 46 намерений есть PowerShell-команды (Get-Process, Get-Service, Get-PSDrive, Get-WinEvent, Test-Connection, Get-NetTCPConnection, Get-PnpDevice, winget…). Агент выбирает набор по ОС цели; модель-планировщик видит поле `os` цели.
- **Подбор по смыслу:** кроме регулярок — нечёткое совпадение основ слов и синонимы («слышать» → микрофон/звук, «лагает» → процессы, «нет интернета» → ping/DNS, «камера» → USB/камеры…); служебные слова («проверь», «покажи») не мешают.
- **Честно:** если запрос не распознан, агент выполняет общий обзор (уже для своей ОС) и в итоге пишет, что в справочнике команд не нашлось, и как уточнить (или дать команду в обратных кавычках).
- Код на цель «облако» на Windows запускается через `& "python.exe" "файл"`.
- Тесты: test_admin216.py (11). На живой Windows-машине не проверялось.
