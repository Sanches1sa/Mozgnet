# v3.197.0 — фотографии для зонной LLM

Визуальный адаптер связывает существующую обработку фотографий с зоной «Камера»: реальные признаки, распознанный текст и доступное описание сцены активируют зону и пополняют её словарный профиль. Сохранённое описание доступно обычному обучению через базу знаний. Веса текстовой LLM не стали зрительными: изображения разбирает адаптер, предметы описывает отдельно подключённая зрительная модель. Автоматическое сохранение описания не означает, что уже выполнен шаг обучения весов.

Загрузка через скрепку в облачном чате передаёт анализ фотографии в следующий вопрос этого чата. Обработка фотографий из МАКС и кадров камер использует тот же адаптер. Исправлен API зрения: ранее строка описания ошибочно обрабатывалась как словарь; теперь возвращаются структурированные результаты, признаки, доступные возможности и настоящий результат сохранения. Ошибочные изображения не отмечаются как успешно распознанные. Добавлены ограничения больших изображений и таймаут OCR. Для зрительной модели передаётся MIME изображения.

## Как пользоваться

1. Обновите облако, перезапустите его и отдельный процесс МАКС, обновите страницу без кэша. Прошивка платы не меняется. Перед установкой сохраните резервную копию data.
2. В чате нажмите скрепку, выберите JPG/PNG и после разбора задайте вопрос. В «Сопряжение» появится активность «Камера», если зонный режим включён.
3. Базовый анализ требует Pillow. Для текста установите Tesseract с языками rus и eng и пакет pytesseract. В Debian/Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng`, затем в Python-окружении облака `python -m pip install pillow pytesseract`.
4. Для предметов и сцен в существующих настройках «API и ответы» включите зрительную LLM, укажите OpenAI-совместимый адрес (например Ollama: http://127.0.0.1:11434/v1) и имя установленной зрительной модели. Текстовая модель без поддержки изображений не подходит. При включении этой функции фотографии передаются указанному серверу; используйте локальный адрес для локальной обработки.

Без OCR текст не извлекается, без зрительной модели объекты не распознаются. Цветовые догадки не выдаются за распознавание. OCR и модель могут ошибаться. Необработанные надписи на фото считаются пользовательскими данными, а не системными инструкциями.

Проверено: 7 новых тестов (PNG, зона, отсутствие обучения по запросу, ошибка файла, формат API, base64, описание сцены и совместимость строкового интерфейса), 9 тестов зонного сопряжения, синтаксис Python/JavaScript. Настоящая зрительная модель и действующий МАКС в среде сборки не подключены.
